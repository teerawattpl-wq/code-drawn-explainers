# code-drawn-explainers

An agent skill for narrated explainer or documentary videos, from one
minute to several, where the picture is drawn by code on a canvas, with narration from a
TTS service and a synthesized soundtrack. It has a menu of looks (sketchbook ink, cut
paper, flat ink, crayon layers, fine line bright) and two optional extras: a cut-out narrator in the corner,
or a sticker puppet with a supporting cast and prop stickers that act in the scenes.

สกิลสำหรับทำสารคดีหรือคลิปอธิบายความรู้ ยาวตั้งแต่หนึ่งนาทีถึงหลายนาที ภาพวาดด้วยโค้ดบน canvas มีเสียงบรรยาย เพลงและเสียงประกอบที่สังเคราะห์ด้วยโค้ด มีเมนูแนวภาพให้เลือก (สมุดสเก็ตช์ กระดาษตัด สีพื้นเส้นขอบดำ ลายสีไม้ซ้อนชั้น เส้นละเอียดสดใส) และมีส่วนเสริมสองอย่างถ้าต้องการ คือผู้เล่าที่มุมจอ หรือหุ่นเชิดสติกเกอร์พร้อมตัวประกอบและของประกอบฉากที่แสดงในฉาก

Start at `code-drawn-explainers/SKILL.md`. A finished one-minute story is in
`code-drawn-explainers/examples/honeycomb/`; one act of a three-minute film with puppets
is in `code-drawn-explainers/examples/mathless/` (code only: its pictures and audio are
not included).


## Notes

- Never commit your `.env` file or API key.
- Use your own characters and write your own stories.
